# Hook lab

## Do
1. Read `wiki/brand-bible.md` (voice) and `wiki/content-playbook.md` (pillars, formats). Check `content/posting-log.md` so ideas do not repeat.
2. Write 10 hooks for the topic Naim gave. Mix the patterns from the playbook: curiosity gap, contrarian, process reveal, before/after, mistake, "POV". Each under 12 words, spoken in the first 2 seconds.
3. Pick the best 3 and write a full script for each: hook (0-2s), setup (2-6s), 3 beats with a visual for each, payoff, call to action. Target 20-40 seconds.
4. One caption per script: hook line, one value line, a question.
5. Rate each script 1-5 on: hook strength, visual clarity, shareability. Explain the weakest score in one line.

## Rules
- Write the way people talk. No corporate words, no "Unlock", no "Elevate".
- Building in public beats polish: real numbers, real mistakes, real process.

## Output
`content/hooks/YYYY-MM-DD-<slug>.md`. Reply with the best hook.
