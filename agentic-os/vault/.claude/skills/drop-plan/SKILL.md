# Drop plan

## Read
`wiki/brand-bible.md`, `projects/clothing-brand.md`, `content/posting-log.md` (what the audience reacted to), and `system/vitals.json`.

## Do
1. **Concept**: 3 concepts, each with a name, a one-line story, who it is for, and which past post proves interest (or "untested").
2. **Pieces**: 1-3 pieces for the chosen concept. Garment, blank (brand/weight/fit), print method, colourways.
3. **Unit economics** per piece: blank + print + shipping + platform and payment fees + return allowance → cost; price; margin in EUR and %. Use real supplier prices from the web with links. Mark anything estimated as an estimate.
4. **Mockups**: 3 image prompts per piece (flat lay, on-model, lifestyle) for Higgsfield, following the brand's visual rules. If a Higgsfield tool is available, you may generate them; label results as AI-generated.
5. **Originality check**: list any element that could resemble an existing logo, artwork or trademark and how to change it.
6. **Launch runway** (21 days): teaser, behind-the-scenes, poll, waitlist push, launch day, follow-up. One line per post, tied to a format from `wiki/content-playbook.md`.
7. **Go / no-go**: the number of waitlist sign-ups or pre-orders that justifies producing stock.

## Never
- Never create products, discounts or orders in Shopify, and never buy anything. Draft only.

## Output
`outputs/drop-plan/YYYY-MM-DD-<slug>.md`. Reply with the chosen concept and its margin.
